# Scraper — Books to Scrape

## Target classification

- **Site:** https://books.toscrape.com
- **Why this site:** Books to Scrape is a purpose-built scraping sandbox
  (per toscrape.com) — a fictional bookstore that exists specifically for
  people to practise scraping techniques on.
- **Scope:** the first 3 catalogue pages only (60 books).
- **Data collected:** title, product URL, price, availability, star
  rating, and description for each book.
- **robots.txt result:** 404 Not Found — no robots.txt file exists at
  https://books.toscrape.com/robots.txt. This is not the same as being
  granted permission; it simply means the site has posted no crawling
  rules. Permission here comes instead from the site's own description
  of itself as a scraping sandbox.
- **Why this is appropriate:** the site explicitly invites scraping and
  contains no personal, private, or paywalled data — it's a sandbox, and
  this project touches nothing else.

I will not reuse this code on another site without checking its rules
and terms first.
